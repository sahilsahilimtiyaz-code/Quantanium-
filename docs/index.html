02. Universal Agent Importers

All Four Agents Ready Out of the Box

Import offline bundles or install directly in-app across .tar.gz, .tgz, .tar.xz, .txz, .zip, .tar, compressed .gz/.xz files, scripts, and raw ARM64 ELF binaries.

Claude Code · ~/.local/share/claude

Universal Bundle & Glibc Wrapper Installer

Extracts archives safely with Zip-Slip path validation, auto-detects versions from package.json or filenames, installs side-by-side versions, updates symlinks, and generates Termux glibc loader wrappers automatically.

OpenCode · ~/.opencode/bin/opencode

NPM Tarballs & Raw ELFs

Unpacks official OpenCode tarballs, zips, or standalone binaries, preserves POSIX 0755 permissions, and refreshes the bridge status immediately on completion.

Codex · ~/.local/bin/codex

ARM64 Binary & Glibc Loader

Detects dynamically linked glibc ELFs inside Codex releases, places the real binary under libexec/, and wires an automatic loader wrapper plus Termux/PRoot symlinks.

Antigravity (agy) · ~/.local/bin/agy

Local Hub Binary & Auto-Restart Wiring

Imports standalone or archived agy CLI releases (with optional bundled language_server companions), installs cleanly into home & Termux bin paths, and triggers immediate bridge availability checks.
